Version 0.1

Initial Beta Release

The first beta of Nofold. It brings poker night to your phone: cards are dealt digitally so nobody can mark them, and every chip is counted automatically. Gather your friends, open the app and deal.

New features

  • NewGame creation: set up a new table in seconds and get a unique game ID.
  • NewJoin by game ID: type in a friend's game ID to take a seat at their table.
  • NewLobby: wait until everyone has joined before the first hand is dealt.
  • NewReal-time multiplayer: every action appears on every device as soon as it happens.
  • NewFull hand flow: every phase of a hand, from pre-flop through flop, turn and river to showdown.
  • NewPlayer actions: check, call, raise and fold.
  • NewAutomatic chip tracking: no more counting chips by hand. Bets and pots are tallied for you.
  • NewHand rankings: standard poker hand rankings decide every showdown.
  • NewResponsive design: works well on phones and tablets of any size.

Under the hood

  • TechEncrypted, secure WebSocket connections for real-time updates
  • TechEfficient state management keeps the UI fast
  • TechRobust error handling for stable sessions

Known issues

  • KnownOccasionally a device gets out of sync with the table. Restarting the app fixes it.
  • KnownTable chat isn't available yet. It's coming in a future update.
